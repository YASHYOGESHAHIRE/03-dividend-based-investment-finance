# Dividend Investing Strategy using Python

This project implements a Dividend-Based Investing Strategy using Python and financial market data. The objective is to identify strong dividend-paying companies that can provide stable income and long-term portfolio growth.

The project demonstrates how financial data analysis and quantitative investing techniques can be used to screen, rank, and analyze dividend stocks.

---

# Overview

Dividend investing focuses on selecting companies that regularly distribute a portion of their profits to shareholders through dividends.

Investors often look for companies with:

- Consistent dividend payments
- High dividend yield
- Strong financial stability
- Sustainable payout ratios
- Long-term growth potential

This project automates dividend stock analysis using Python.

---

# Features

- Import and process stock market data
- Analyze dividend-related metrics
- Calculate dividend yield
- Rank dividend-paying stocks
- Portfolio screening and filtering
- Financial data preprocessing and cleaning
- Investment recommendation generation

---

# Financial Metrics Used

Some important dividend investing metrics included in this project:

- Dividend Yield
- Dividend Payout Ratio
- Earnings Per Share (EPS)
- Price-to-Earnings Ratio (P/E)
- Market Capitalization
- Revenue and Profitability Metrics

# Technologies Used

# Project Workflow

1. Load stock universe
2. Retrieve financial and dividend data
3. Clean and preprocess data
4. Handle missing values
5. Calculate dividend metrics
6. Rank stocks based on dividend performance
